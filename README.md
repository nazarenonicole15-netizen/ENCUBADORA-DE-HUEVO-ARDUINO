# Incubadora de Huevos con Arduino 🐣

Bienvenido al repositorio del proyecto **Incubadora de Huevos con Arduino**.

Este proyecto consiste en un sistema completo de monitoreo y control para una incubadora, con una arquitectura que incluye:

- **Hardware / IoT:** Arduino/ESP con sensores DHT11/DHT22 conectado a ThingSpeak.
- **Base de Datos:** MySQL / MariaDB.
- **Backend:** Node.js + Express (API y Worker para sincronizar datos de ThingSpeak).
- **Frontend:** Panel de control en Vue 3 + Vite + TailwindCSS.
